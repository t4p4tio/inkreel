# Inkreel

A Windows app that turns a movie into a comic-style graphic novel. This repository holds only Inkreel's
download page and its releases; the app's source isn't published.

- **Download page:** https://t4p4tio.github.io/inkreel/
- **Newest version:** https://github.com/t4p4tio/inkreel/releases/latest

Inkreel checks this repository's newest release for updates. Every release's `latest.json` is signed with
Inkreel's release key, and Inkreel installs only what that key signed.
